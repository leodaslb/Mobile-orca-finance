Aluno(a): LEONARDO DA SILVA LOPES BEZERRA
Nome do aplicativo: Orca Finance
O aplicativo Orca Finance é uma ferramenta abrangente de gestão
financeira pessoal projetada para auxiliar os usuários a
entenderem seus hábitos de consumo, controlarem gastos por
impulso e alcançarem metas de economia. O aplicativo utiliza o
React Native para oferecer uma experiência nativa no sistema
Android, combinando funcionalidades de orçamento, rastreamento
de despesas e mecanismos de reflexão para promover uma relação
mais saudável com o dinheiro. Seu desenvolvimento foca em
fornecer um conjunto robusto de desafios de programação que
abrangem desde a manipulação de dados locais até a integração
com APIs externas e o uso de sensores do dispositivo, tudo
dentro do ecossistema Node.js e React Native.
O aplicativo deve permitir que o usuário registre manualmente
cada transação financeira, categorizando-a entre receitas e
despesas, com campos para valor, data, hora e uma descrição
detalhada.
Para um controle mais granular, o sistema deve possibilitar a
criação de subcategorias personalizadas dentro das categorias
principais, como "Alimentação" com subcategorias "Restaurante",
"Supermercado" e "Lanches".
Uma funcionalidade essencial é a capacidade de definir um
orçamento mensal para cada categoria de gasto, com o aplicativo
fornecendo alertas visuais quando o usuário se aproximar ou
exceder o limite estabelecido.
O Orca Finance deve implementar um sistema de "metas de
economia", onde o usuário pode definir um objetivo financeiro
com um valor alvo e uma data limite, e o aplicativo calcula e
sugere um valor de economia diário ou semanal.
Para desencorajar compras por impulso, o aplicativo deve
incluir um recurso de "período de reflexão", onde o usuário
pode adicionar um item desejado a uma lista de espera, e o
sistema só libera a opção de compra após um intervalo de tempo
pré-definido, como 24 horas.
O sistema deve gerar relatórios detalhados de gastos em formato
gráfico, como gráficos de pizza e de barras, que demonstram a
distribuição dos gastos por categoria ao longo de um período
selecionado.
O usuário deve poder exportar seus dados financeiros para um
arquivo CSV, permitindo uma análise externa ou o backup das
informações.
Para uma visão holística, o aplicativo deve exibir um painel de
controle principal que resume o saldo atual, os gastos do mês,
o progresso das metas de economia e um comparativo com o mês
anterior.
O sistema de notificações push deve ser inteligente, enviando
lembretes para registrar transações que podem ter sido
esquecidas, baseando-se no histórico de gastos do usuário ou em
horários pré-definidos.
Uma funcionalidade de "desafio de economia" deve propor ao
usuário um período (ex: 30 dias) para economizar uma quantia
específica, com atualizações de progresso e mensagens de
incentivo.
O aplicativo deve suportar múltiplos perfis financeiros,
permitindo que o usuário gerencie, por exemplo, uma conta
pessoal e uma conta conjunta separadamente.
Para melhorar a precisão dos dados, o usuário pode anexar uma
foto do recibo da compra ao registrar uma despesa, utilizando a
câmera do dispositivo.
O aplicativo deve permitir a busca e filtragem de transações
por data, categoria, descrição ou valor, facilitando a
localização de registros específicos.
O Orca Finance deve oferecer uma visão preditiva, analisando os
padrões de gastos para estimar o saldo no final do mês, com
base nas despesas e receitas programadas.
O sistema deve suportar a criação de regras de automação, como
"sempre que eu registrar um gasto em 'Transporte', classificar
como 'Essencial'".
A sincronização dos dados entre diferentes dispositivos deve
ser implementada, garantindo que o usuário tenha acesso às suas
informações financeiras em qualquer lugar.
O aplicativo deve integrar uma API de conversão de moedas para
permitir que o usuário registre gastos em diferentes moedas,
que serão automaticamente convertidas para a moeda base do
perfil.
Para combater compras impulsivas em aplicativos de comércio
eletrônico, o sistema deve permitir ao usuário configurar uma
lista de aplicativos "gatilho" que, quando abertos, disparam
uma notificação com uma pergunta reflexiva sobre a necessidade
da compra.
O módulo de "educação financeira" deve exibir pequenos artigos
ou dicas diárias sobre economia, investimentos e controle de
gastos, com a possibilidade de o usuário marcar os que já leu.
O usuário deve poder registrar receitas recorrentes, como
salário, e despesas fixas, como aluguel, configurando-as para
serem adicionadas automaticamente ao extrato em datas
específicas.
Um sistema de tags deve ser implementado, permitindo ao usuário
marcar transações com palavras-chave (ex: #viagem, #urgente)
para uma categorização e busca ainda mais flexíveis.
O aplicativo deve calcular e exibir métricas financeiras
importantes, como a taxa de poupança (percentual da renda que é
economizado) e o saldo médio diário.
Para promover a transparência, o histórico completo de todas as
alterações feitas em uma transação (edição, exclusão) deve ser
registrado e acessível ao usuário.
O aplicativo deve permitir a criação de um orçamento de
"inclusão digital", onde o usuário pode definir limites para
gastos com assinaturas de streaming, aplicativos e serviços
online.
Um recurso de "simulador de compras" deve permitir que o
usuário insira o valor de um bem desejado para visualizar o
impacto dessa compra em seu orçamento mensal ao longo do tempo.
O sistema deve fornecer um "resumo semanal" dos gastos, enviado
por notificação push, que destaca os maiores gastos e o
progresso em relação ao orçamento.
O Orca Finance deve possibilitar que o usuário defina um limite
máximo de gastos diário, com um alerta sendo disparado sempre
que esse limite for atingido.
Para uma análise mais profunda, o usuário pode exportar seus
dados financeiros para um formato compatível com ferramentas de
planilha, como o Excel.
O aplicativo deve incluir um recurso para digitalizar recibos
usando a câmera, utilizando uma biblioteca de reconhecimento
óptico de caracteres (OCR) para extrair automaticamente dados
como valor, data e estabelecimento.
O sistema deve permitir que o usuário compartilhe o progresso
de suas metas de economia com contatos selecionados, como um
parceiro ou um amigo para fins de motivação.
Um "modo escuro" deve ser implementado para melhorar a
usabilidade do aplicativo em ambientes com pouca luz,
respeitando as configurações de tema do sistema Android.
O aplicativo deve oferecer uma ferramenta para calcular o valor
de juros compostos, ajudando o usuário a visualizar o potencial
de crescimento de seus investimentos a longo prazo.
Para categorizar transações automaticamente, o sistema deve
aprender com as ações do usuário, sugerindo a categoria correta
para uma nova despesa baseada em descrições anteriores
semelhantes.
O usuário deve poder definir um orçamento para um período
específico que não seja mensal, como semanal ou anual, para
atender a necessidades de planejamento diferenciadas.
O Orca Finance deve implementar um sistema de "taxa de
realização de metas", que calcula a porcentagem de metas de
economia que o usuário conseguiu cumprir nos últimos meses.
O aplicativo deve permitir a inclusão de anotações em cada
transação, proporcionando um contexto adicional que pode ser
útil para revisões futuras.
Um recurso de "planejador de grandes compras" deve ajudar o
usuário a criar um plano de economia para um bem de alto valor,
dividindo o custo total em parcelas mensais que caibam em seu
orçamento.
O sistema deve fornecer uma visão clara do fluxo de caixa,
apresentando uma projeção de entradas e saídas de dinheiro para
os próximos 30 dias, com base em dados recorrentes e agendados.
Para lidar com finanças compartilhadas, o aplicativo deve
permitir que o usuário marque uma transação como
"compartilhada" e calcule a parte que cabe a cada envolvido.
O aplicativo deve oferecer uma funcionalidade para reverter uma
transação, caso o usuário a tenha registrado por engano, com um
fluxo claro para fazer a correção.
Um painel de "gastos por localização" deve ser implementado,
utilizando o GPS do telefone para categorizar gastos com base
no estabelecimento onde a compra foi realizada.
O sistema deve permitir a criação de múltiplos orçamentos
temporários, como um orçamento específico para uma viagem ou
para um projeto pessoal.
O Orca Finance deve incluir um jogo de simulação onde o usuário
toma decisões financeiras em cenários hipotéticos para aprender
sobre consequências de escolhas de consumo.
O aplicativo deve fornecer uma análise de tendências, mostrando
se os gastos do usuário em cada categoria estão aumentando,
diminuindo ou se mantendo estáveis ao longo dos meses.
Para um registro mais rápido, o aplicativo deve permitir a
criação de um atalho na tela inicial do Android que abre
diretamente a tela de registro de uma nova transação.
O sistema deve permitir que o usuário estabeleça um "orçamento
zero" (zero-based budget), onde cada real da renda é destinado
a uma categoria específica, promovendo um planejamento mais
rigoroso.
O aplicativo deve gerar um "certificado de economia" ao final
de um desafio bem-sucedido, que pode ser compartilhado em redes
sociais ou guardado como registro.
Para proteger os dados sensíveis, o aplicativo deve oferecer a
opção de bloqueio por biometria (impressão digital ou
reconhecimento facial) ou por um PIN, utilizando as APIs de
autenticação do Android.
O sistema deve integrar uma API de notícias financeiras para
exibir ao usuário um feed de artigos relevantes sobre economia
e mercado.
O Orca Finance deve permitir que o usuário personalize as cores
dos gráficos e do tema do aplicativo, adaptando a interface ao
seu gosto pessoal.
Um recurso de "análise de custo de oportunidade" deve ser
implementado, mostrando ao usuário o quanto um gasto presente
poderia se tornar no futuro se fosse investido.
O aplicativo deve oferecer a opção de realizar um "check-in"
financeiro, onde o usuário responde a perguntas sobre seu
estado emocional e hábitos de consumo, e o sistema oferece um
feedback personalizado.
Para promover a sustentabilidade, o aplicativo deve calcular e
exibir a "pegada de carbono" estimada com base nos padrões de
consumo do usuário (ex: gastos com combustível, energia).
O sistema deve permitir que o usuário configure alertas para
quando uma categoria de gasto específica ultrapassar um limite
definido, com a opção de receber a notificação por e-mail ou
push.
O aplicativo deve fornecer uma funcionalidade para comparar o
orçamento planejado com o realizado, destacando as variações e
as categorias que mais contribuíram para a diferença.
Um modo "avião financeiro" deve ser implementado para bloquear
temporariamente o acesso a todas as funções do aplicativo,
exceto a visualização, para momentos de pausa planejada.
O sistema deve permitir que o usuário defina uma "cota de
gastos livres", um valor mensal que pode ser gasto sem
categorização, para dar flexibilidade ao orçamento.
Para um controle mais preciso, o Orca Finance deve suportar o
registro de despesas com métodos de pagamento específicos
(dinheiro, cartão de crédito, débito, etc.), permitindo filtrar
por eles.
O aplicativo deve permitir a criação de um "diário de consumo",
onde o usuário pode escrever livremente sobre suas motivações
para comprar algo, ajudando na autorreflexão.
O sistema deve fornecer uma previsão do impacto de uma compra
parcelada no orçamento dos próximos meses, mostrando o
comprometimento da renda futura.
O usuário deve poder importar dados financeiros de um arquivo
CSV ou de um extrato bancário, desde que siga um formato
predefinido, para não precisar registrar tudo manualmente.
O aplicativo deve exibir um indicador de "saúde financeira",
uma pontuação calculada com base em múltiplas métricas, como
dívidas, poupança e controle de gastos.
O sistema deve permitir a criação de um "orçamento por evento",
como um casamento ou uma festa de aniversário, onde todos os
gastos relacionados são agrupados e acompanhados.
O Orca Finance deve possibilitar que o usuário defina lembretes
para datas de vencimento de contas, associando a conta a uma
transação futura programada.
Um recurso de "desafio de despesas essenciais" deve incentivar
o usuário a reduzir gastos em uma categoria específica,
sugerindo alternativas mais econômicas.
Para auxiliar na decisão de compra, o aplicativo deve permitir
que o usuário compare o preço de um produto desejado com a sua
média de preços dos últimos meses.
O sistema deve oferecer a opção de "modo de apresentação", que
oculta valores monetários e exibe apenas o progresso em
porcentagem para compartilhar com outras pessoas.
O usuário deve poder configurar o aplicativo para receber um
resumo financeiro mensal em formato de relatório PDF, que pode
ser salvo ou compartilhado.
O aplicativo deve implementar um sistema de conquistas
(gamificação), onde o usuário ganha distintivos por ações como
economizar por um mês seguido ou completar um desafio.
Para promover hábitos conscientes, o aplicativo deve exibir uma
frase ou pergunta reflexiva toda vez que o usuário estiver
prestes a finalizar o registro de uma compra não essencial.
O sistema deve permitir a criação de "regras de gastos", como
"gastos com lazer não podem exceder 10% da renda mensal", e
alertar o usuário quando a regra for violada
